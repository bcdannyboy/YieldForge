# Appendix D. Glossary

Key terms used consistently throughout the proposal.

| Term | Definition |
| --- | --- |
| Candidate nest | A complete feasible placement of the current part batch on a particular stock object. |
| Current-state baseline | A policy limited to information genuinely known at the decision timestamp. |
| Exact remnant | A connected residual polygon retained as inventory after subtracting parts and process loss. |
| Geometric upper bound | A permissive extraction treating every eligible empty connected component as recoverable. |
| Known-order lookahead | Optimization using orders already released or scheduled, excluding later uncommitted demand. |
| Marginal option value | The reduction in expected future cost caused by adding a remnant to the existing inventory state. |
| Oracle advantage | Net cost difference between the strongest current-state baseline and the perfect-information policy. |
| Perfect-information policy benchmark | A policy that sees the realized future but may still use approximate search; not automatically a mathematical upper bound. |
| Recoverability gap | Difference between savings under ideal geometric remnants and conservative operational remnants. |
| Residual topology | Connectivity, shape, width, edge access, holes, and other structural properties of unused material. |
| Search gap | Difference between perfect-information performance under ordinary versus expanded candidate generation. |
| Terminal inventory rule | How remnants remaining at the end of a finite benchmark horizon are valued or liquidated. |
