# M1 — Minimal canonical model

**Status:** Later

The `yf/` foundation contains intentionally narrow part, strip-problem, placement, and candidate contracts needed by the Spyrrow boundary. M1 remains open because order, stock, remnant, state, provenance, transform, and canonical-identity acceptance tests are not defined yet.

M1 gives every component the same language for parts, order events, stock, placements, candidates, remnants, inventory states, decisions, and provenance. It should be the smallest executable contract that supports one end-to-end fixture, not a months-long attempt to design every future schema.

> **Question:** Can every component describe the same physical and economic state without ambiguity or geometry drift?

## Acceptance boundary

The canonical fixture survives import, export, coordinate transforms, and canonical identity checks within declared tolerances.

## Not yet

Detailed design begins only after M0 passes.
