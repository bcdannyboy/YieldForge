## Acceptance boundary

The same manifest reproduces a stable set of feasible, near-tied but materially different placement layouts.

“Data” here means static geometry, not manufacturer history or the full temporal benchmark.

Passing M2 proves only that the source-recorded solver path produced a sufficiently rich near-tied
geometric action space under this bounded corpus and configuration. It does not prove residual
diversity, remnant utility, material savings, solver optimality, physical recoverability, or
commercial value. Exact residual equivalence now belongs to M3; the registered no-flip ablation
and repeatability subset remain supporting diagnostics rather than substitutes for residual truth.
